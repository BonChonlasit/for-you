# เว็บเซอร์ไพรส์วันเกิด 🎂

เว็บไซต์ 8 ด่านสำหรับเปิดบน iPad แนวนอนหรือบนคอม

1. **ล็อกหน้าแรก** — กดรหัส (วันครบรอบ) เพื่อเปิดกล่องของขวัญ
2. **เปิดเรื่อง** — ข้อความขึ้นทีละบรรทัด มีฉากพิมพ์แชทแล้วลบทิ้ง
3. **ควิซ "รู้จักเค้าแค่ไหน"** — ตอบถูกมีรูป/ข้อความ ตอบผิดโดนแซว จบแล้วได้ตราปั๊มคะแนน
4. **เกมจับคู่รูป** — การ์ด 12 ใบเรียงเป็นหัวใจ
5. **แกลเลอรีโพลารอยด์** — แตะรูปเพื่อพลิกดูวันที่และเรื่องราว
6. **จดหมายรัก** — แตะตราหัวใจ ซองเปิด ตัวหนังสือพิมพ์ขึ้นทีละตัว
7. **คำถามสำคัญ** — ปุ่ม "ไม่เอา" วิ่งหนี ปุ่ม "ได้สิ" ใหญ่ขึ้นเรื่อยๆ
8. **เค้กวันเกิด** — เป่าเทียนผ่านไมค์จริง ไฟดับแป๊บนึง แล้วกระดาษสีโปรยลงมาพร้อมเพลง Happy Birthday

ระหว่างทาง เค้กเล็กๆ มุมซ้ายบนจะสูงขึ้นทีละชั้นทุกครั้งที่ผ่านด่าน

---

## แก้เนื้อหา

แก้ทุกอย่างได้ใน **`config.js`** ไฟล์เดียว (เปิดด้วย Notepad หรือ VS Code ก็ได้)

| อยากแก้ | หาคำว่า |
|---|---|
| ชื่อแฟน / ชื่อเรา | `name`, `from` |
| รหัสหน้าแรก | `passcode` (ค่าเริ่มต้นคือ `1402`) |
| ข้อความเปิดเรื่อง | `intro` |
| คำถามควิซ | `quiz` → `questions` (`answer` นับจาก 0: ก=0, ข=1, ค=2, ง=3) |
| รูป + วันที่ + เรื่องราว | `photos` |
| จดหมาย | `letter` → `body` (หนึ่งบรรทัดในวงเล็บ = หนึ่งย่อหน้า) |
| จำนวนเทียน | `cake` → `candles` |

ในข้อความ ใช้ `{name}` แทนชื่อแฟน และ `{from}` แทนชื่อเรา

## ใส่รูป

- วางรูปในโฟลเดอร์ `photos/` ตั้งชื่อ `01.jpg`, `02.jpg`, … ให้ตรงกับ `photos` ใน `config.js`
- รูปที่ยังไม่มี เว็บจะโชว์กรอบสีพาสเทลพร้อมชื่อไฟล์แทน จะได้รู้ว่าขาดรูปไหน
- เกมจับคู่ใช้ 6 รูปแรก
- **ย่อรูปก่อน** (ด้านยาวประมาณ 1600px) เว็บจะโหลดเร็วขึ้นมาก รูปจากมือถือขนาด 4–5MB ต่อรูปจะทำให้เปิดช้า
- ใช้ไฟล์ `.jpg` หรือ `.png` (ไฟล์ `.heic` จาก iPhone เปิดบนคอม Windows ไม่ได้)

## ใส่เพลง

วางไฟล์เพลงชื่อ `song.mp3` ไว้ในโฟลเดอร์ `music/` เพลงจะเริ่มเล่นตอนใส่รหัสถูก และมีปุ่มเปิด/ปิดเพลงมุมขวาบน
ถ้าไม่ใส่เพลง ปุ่มเพลงจะซ่อนไปเอง (เสียงเอฟเฟกต์กับเพลง Happy Birthday ตอนเป่าเค้กสร้างจากโค้ด ไม่ต้องมีไฟล์)

## ลองบนคอม

- ดับเบิลคลิก `index.html` ได้เลย
- ข้ามไปด่านที่อยากดู: ต่อท้ายลิงก์ด้วย `?scene=quiz` (มี `lock`, `intro`, `quiz`, `memory`, `gallery`, `letter`, `ask`, `cake`)
- ต่อท้ายด้วย `?dev` จะมีปุ่ม ◀ ▶ ไว้ข้ามด่านตอนแก้งาน
- ไมค์อาจใช้ไม่ได้ตอนเปิดจากไฟล์ตรงๆ ในบางเบราว์เซอร์ ถ้าเป็นแบบนั้นแตะที่เปลวเทียนแทนได้ พอเอาขึ้นเว็บ (https) ไมค์จะใช้ได้

## เอาขึ้นเว็บ (ฟรี) เพื่อเปิดบน iPad

ไมค์บน iPad ใช้ได้เฉพาะเว็บที่เป็น **https** เลยต้องเอาขึ้นเว็บก่อน เลือกทางใดทางหนึ่ง:

- **Netlify Drop** — เข้า https://app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ไปวาง จะได้ลิงก์ทันที (สมัครบัญชีเพื่อเก็บลิงก์ไว้ถาวร)
- **GitHub Pages** — อัปโฟลเดอร์นี้ขึ้น repo แล้วเปิด Settings → Pages

> ลิงก์เว็บประเภทนี้ ใครมีลิงก์ก็เปิดได้ อย่าใส่รูปที่ไม่อยากให้คนอื่นเห็น

## เปิดบน iPad

1. เปิดลิงก์ใน Safari แล้วหมุนเป็นแนวนอน
2. แนะนำ: กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** แล้วเปิดจากไอคอน จะได้เต็มจอไม่มีแถบเบราว์เซอร์
3. เปิดเสียง iPad และลองเล่นจนจบเองก่อน 1 รอบ
4. ตอนเป่าเทียน iPad จะถามขอใช้ไมค์ ให้กด **อนุญาต**
5. ถ้าเป่าแล้วเทียนไม่ดับ เพิ่ม `sensitivity` ใน `config.js` เป็น `1.5`–`2` / ถ้าแค่พูดแล้วเทียนดับเอง ลดเป็น `0.6`
