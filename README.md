# เว็บเซอร์ไพรส์วันเกิด 🎂

ลิงก์: https://bonchonlasit.github.io/for-you/

เว็บไซต์ 9 ด่านสำหรับเปิดบน iPad แนวนอนหรือบนคอม

0. **กระจกฝ้า + กล้องจับมือ** — เปิดกล้อง โบกมือเช็ดฝ้า แล้วทำมือรูปหัวใจกลางจอด้วยกันเพื่อผ่านด่าน
1. **ล็อกหน้าแรก** — กดรหัส (วันครบรอบ) เพื่อเปิดกล่องของขวัญ
2. **เปิดเรื่อง** — ข้อความขึ้นทีละบรรทัด มีฉากพิมพ์แชทแล้วลบทิ้ง
3. **ควิซ "รู้จักเค้าแค่ไหน"** — ตอบถูกมีรูป/ข้อความ ตอบผิดโดนแซว จบแล้วได้ตราปั๊มคะแนน
4. **เกมจับคู่รูป** — การ์ด 12 ใบเรียงเป็นหัวใจ
5. **แกลเลอรีโพลารอยด์** — แตะรูปเพื่อพลิกดูวันที่และเรื่องราว
6. **จดหมายรัก** — แตะตราหัวใจ ซองเปิด ตัวหนังสือพิมพ์ขึ้นทีละตัว
7. **คำถามสำคัญ** — ปุ่ม "ไม่เอา" วิ่งหนี ปุ่ม "ได้สิ" ใหญ่ขึ้นเรื่อยๆ
8. **เค้กวันเกิด** — เป่าเทียนผ่านไมค์จริง ไฟดับแป๊บนึง แล้วกระดาษสีโปรยลงมาพร้อมเพลง Happy Birthday จากนั้นเค้กหลบไป แล้วภาพคอลลาจของเราสองคน (`photos/us.webp`) ลอยขึ้นมาเป็นฉากจบ (แตะภาพ = หัวใจกระจาย)

บนจอแทบไม่มีข้อความสอนแล้ว ทริคที่ซ่อนอยู่:
- ระหว่างข้อความเปิดเรื่อง แตะจอ = ข้ามไปบรรทัดถัดไป
- ระหว่างจดหมายกำลังพิมพ์ แตะจดหมาย = ขึ้นทั้งหมดทันที
- หน้าเค้ก ถ้าไมค์ใช้ไม่ได้ แตะที่เปลวเทียนทีละเล่มแทนได้

## ด่านกระจกฝ้า (กล้องจับมือ)

- กด "เปิดกล้อง" แล้วกดอนุญาตให้ใช้กล้อง ภาพจะเหมือนมองผ่านกระจกที่ขึ้นฝ้า
- **โบกมือไปมา** ฝ้าจะหายตามมือ มีหยดน้ำไหลลงตามรอยเช็ด ฝ้าขึ้นรอบเดียว เช็ดแล้วหายเลย (ใช้นิ้วลากบนจอเช็ดได้ด้วย / อยากให้ฝ้ากลับมา ตั้ง `camera.fogReturnSeconds` เป็นจำนวนวินาที)
- **ผ่านด่าน:** ทำมือรูปหัวใจตรงกลางจอแล้วค้างไว้ **10 วินาที** (`camera.holdSeconds`) จะคนเดียวสองมือ หรือสองคนคนละมือก็ได้ ระหว่างค้าง หัวใจกลางจอจะค่อยๆ เต็มและเรืองแสง มีหัวใจลอยขึ้นจากมือถี่ขึ้นเรื่อยๆ พร้อมเสียงหัวใจเต้น (มือหลุดแป๊บเดียวเวลาไม่ลด) ผ่านแล้วจะมีหัวใจยักษ์ พลุ และรูปโพลารอยด์ตอนทำหัวใจ (กด "บันทึกรูป" เก็บไว้ได้)
- **ท่าเล่นระหว่างรอ** (ไว้ถ่ายคลิป ไม่มีป้ายบอกบนจอ):

  | ท่า | เอฟเฟกต์ |
  |---|---|
  | ✋ แบมือแล้วโบก | หัวใจ ดาว เค้กจิ๋ว ร่วงลงมา |
  | ☝️ ชี้นิ้ว | วาดเส้นแสงพาสเทลกลางอากาศ (ลองวาดหัวใจ) |
  | ✌️ ชูสองนิ้ว | ดาววิ้งๆ ที่ปลายนิ้ว |
  | ✊ กำมือค้างไว้ แล้วแบออก | พลุหัวใจระเบิดจากมือ |
  | 🫰 มินิฮาร์ท (นิ้วโป้งไขว้นิ้วชี้) | หัวใจดวงเล็กลอยขึ้น |

- ปุ่มกลมมุมขวาล่าง: **🎬** ซ่อนปุ่มทั้งหมดให้เหลือแต่ภาพกับเอฟเฟกต์ (แตะจอเพื่อให้ปุ่มกลับมา) ส่วน **✨** โชว์เส้นโครงมือเรืองแสง
- ถ่ายคลิปบน iPad: ใช้การบันทึกหน้าจอจากศูนย์ควบคุม
- ทริค: อยู่ในที่สว่าง ให้เห็นมือชัดๆ ห่างจอประมาณ 50–100 ซม.
- ถ้ากล้องเปิดไม่ได้หรือทำไม่ผ่านภายใน 40 วินาที จะมีปุ่ม "ข้ามด่านนี้" โผล่มา
- ไม่อยากใช้ด่านนี้: ตั้ง `camera.enabled` เป็น `false` (ในหน้า admin หรือ `config.js`)
- ระบบจับมือใช้ [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) โหลดจากอินเทอร์เน็ตตอนเปิดหน้า (ครั้งแรกประมาณ 20MB) ภาพจากกล้องไม่ถูกส่งไปไหน ประมวลผลในเครื่องทั้งหมด

## อัดวิดีโอเก็บไว้ (ปุ่ม ⏺ มุมขวาบน)

- กด ⏺ ตอนเริ่ม แล้วเล่นไปตามปกติ ปุ่มจะกลายเป็นจุดแดงกระพริบพร้อมเวลา กดอีกครั้งเพื่อหยุด
- พอหยุดจะมีหน้าดูคลิป กด **บันทึกวิดีโอ**: บนคอมจะดาวน์โหลดไฟล์ (.mp4) บน iPad จะเปิดแผ่นแชร์ให้เลือก "บันทึกวิดีโอ" ลงแอปรูปภาพ
- คลิปคือภาพหน้าจอจริงทุกอย่าง + เสียงของเว็บ (เพลง เอฟเฟกต์ เพลงวันเกิด) แต่**ไม่มีเสียงคนพูด**
- บนคอมใช้ Chrome หรือ Edge จะดีที่สุด (กดแล้วเลือก "แท็บนี้")
- บน iPad ปุ่มนี้ใช้ได้ตั้งแต่ iPadOS 27 ขึ้นไป ถ้าเครื่องยังไม่รองรับจะขึ้นบอก ให้ใช้ **อัดหน้าจอของ iPad** แทน (ปัดเปิดศูนย์ควบคุม → ⏺) ซึ่งเก็บภาพและเสียงได้เหมือนกัน และกดค้างที่ปุ่มเพื่อเปิดไมค์ อัดเสียงเราสองคนไปด้วยได้ ไฟล์จะเข้าแอปรูปภาพเอง
- ตอนอยู่ในโหมด 🎬 ของด่านกล้อง ปุ่ม ⏺ จะซ่อนด้วย แตะจอเพื่อให้กลับมา

## แก้เนื้อหาผ่านหน้า admin (แนะนำ)

- เปิด `https://bonchonlasit.github.io/for-you/admin.html` หรือ **แตะมุมซ้ายบนของเว็บ 5 ครั้งติดกัน**
- แก้ได้ทุกอย่าง: ชื่อ รหัส ข้อความ ควิซ (เลือกข้อถูกได้) รูป เพลง จดหมาย เค้ก
- **รูปและข้อความที่ใส่ในหน้า admin เก็บไว้ในเครื่องนั้นเท่านั้น** ไม่ได้อัปขึ้นเว็บ คนอื่นที่เปิดลิงก์จะไม่เห็นรูปของเรา
- เพราะฉะนั้นให้ตั้งค่าบน **iPad เครื่องที่จะใช้เซอร์ไพรส์**
- ถ้าเพิ่มเว็บไว้ที่หน้าจอโฮมของ iPad แอปบนหน้าจอโฮมจะมีที่เก็บข้อมูลแยกจาก Safari ให้เปิดแอปจากไอคอนก่อน แล้วแตะมุมซ้ายบน 5 ครั้งเพื่อเข้าหน้า admin จากในแอป
- ตั้งค่าบนคอมแล้วจะย้ายไป iPad: กด "สำรองข้อมูล" บนคอม ส่งไฟล์ไป iPad แล้วกด "นำเข้า" ในหน้า admin บน iPad
- กดสำรองข้อมูลเก็บไว้ด้วย เผื่อ Safari ล้างข้อมูลเว็บที่ไม่ได้เปิดนาน

## แก้เนื้อหาผ่านไฟล์ (ค่าเริ่มต้นของทุกเครื่อง)

ค่าเริ่มต้นอยู่ใน **`config.js`** ไฟล์เดียว ถ้าหน้า admin ในเครื่องไหนบันทึกค่าไว้ ค่าจาก admin จะทับค่าในไฟล์

| อยากแก้ | หาคำว่า |
|---|---|
| ชื่อแฟน / ชื่อเรา | `name`, `from` |
| รหัสหน้าแรก | `passcode` (ตอนนี้คือ `2005`) |
| ด่านกล้อง | `camera` |
| ข้อความเปิดเรื่อง | `intro` |
| คำถามควิซ | `quiz` → `questions` (`answer` นับจาก 0: ก=0, ข=1, ค=2, ง=3) |
| รูป + วันที่ + เรื่องราว | `photos` |
| จดหมาย | `letter` → `body` (หนึ่งบรรทัดในวงเล็บ = หนึ่งย่อหน้า) |
| จำนวนเทียน | `cake` → `candles` |

ในข้อความ ใช้ `{name}` แทนชื่อแฟน และ `{from}` แทนชื่อเรา

- รูป: วางในโฟลเดอร์ `photos/` ชื่อ `01.jpg`, `02.jpg`, … (ไฟล์ในโฟลเดอร์นี้ขึ้นเว็บสาธารณะ ใครก็เห็นได้)
- เพลง: `music/song.mp3` (ไม่ใส่ก็ได้)

## ลองบนคอม

- เปิดลิงก์เว็บได้เลย หรือดับเบิลคลิก `index.html`
- ข้ามไปด่านที่อยากดู: ต่อท้ายลิงก์ด้วย `?scene=quiz` (มี `camera`, `lock`, `intro`, `quiz`, `memory`, `gallery`, `letter`, `ask`, `cake`)
- ต่อท้ายด้วย `?dev` จะมีปุ่ม ◀ ▶ ไว้ข้ามด่านตอนแก้งาน

## เปิดบน iPad

1. เปิดลิงก์ใน Safari แล้วหมุนเป็นแนวนอน
2. แนะนำ: กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** แล้วเปิดจากไอคอน จะได้เต็มจอ
3. เปิดเสียง iPad แล้วเล่นจนจบเองก่อน 1 รอบ
4. iPad จะถามขอใช้กล้อง (ด่านแรก) และไมค์ (ตอนเป่าเทียน) ให้กด **อนุญาต**
5. ถ้าเป่าแล้วเทียนไม่ดับ เพิ่มความไวไมค์ (`cake.sensitivity`) เป็น `1.5`–`2` / ถ้าแค่พูดแล้วเทียนดับเอง ลดเป็น `0.6`
